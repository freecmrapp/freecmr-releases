# FreeCMR Desktop

Downloads for the FreeCMR desktop app — a free cardiovascular MRI (CMR)
viewer and analysis tool for research and education.

**Not for clinical use.**

- Website: https://freecmr.app
- Browser version (no install): https://freecmr.app/lite/index.html
- Manual (PDF): https://freecmr.app/download.html

## Download

See the [Releases](../../releases) page for the latest Windows build.

This repository exists only to host release downloads — it does not contain
the application's source code.
